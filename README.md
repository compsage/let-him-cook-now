# Let Him Cook Now 🔥🔥🔥

A VS Code extension that displays cooking GIFs with background music right in your editor. Perfect for when you need that extra boost while coding!

## Features

- Display random cooking GIFs
- Background music player
- Auto-play mode that cycles through GIFs automatically
- Configurable display duration
- Animated UI with always-visible controls

## Usage

### Opening the Extension

Find "🔥🔥🔥" in the Activity Bar sidebar to open the GIF viewer.

### Controls

- **▶/⏸ Music Button** (top right of GIF, shows on hover) - Play/pause music
- **⏭ Skip Button** (title bar) - Next GIF

## Configuration

Open VS Code Settings and search for "funnyCookingGifs" to customize:

- **Display Duration** - How long to show each GIF in seconds (default: 5)
- **Auto Play** - Automatically cycle through GIFs (default: true)

Example settings:

```json
{
  "funnyCookingGifs.displayDuration": 90,
  "funnyCookingGifs.autoPlay": true
}
```

## Requirements

- VS Code 1.60.0 or higher
